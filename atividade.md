1. Processo: Registro de pedidos
Requisito 1. O sistema deve permitir que o vendedor registre um pedido informando o cliente, os produtos, as quantidades e a forma de pagamento.
Fonte 1. Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.
Fonte 2. Política comercial da empresa sobre as informações obrigatórias do pedido. Fonte não humana, categoria documentação.
Requisito 2. O sistema deve verificar a disponibilidade dos produtos antes de confirmar o pedido.
Fonte 1. Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.
Fonte 2. Entrevista com o responsável pelo estoque. Fonte humana, nível operacional, classe de usuário estoque.
Fonte 3. Sistema utilizado atualmente para controle de estoque, caso exista. Fonte não humana, categoria sistema legado.
Requisito 3. O sistema deve permitir que o vendedor consulte os pedidos registrados e seus respectivos status.
Fonte 1. Entrevista com vendedores. Fonte humana, nível operacional, classe de usuário vendedor.
Fonte 2. Entrevista com o gerente comercial. Fonte humana, nível tático.
2. Processo: Cadastro e remoção de produtos
Requisito 4. O sistema deve permitir que o administrador cadastre um produto informando, no mínimo, nome, descrição, preço e código do produto.
Fonte 1. Entrevista com o administrador. Fonte humana, nível operacional, classe de usuário administrador.
Fonte 2. Documentação interna sobre o cadastro de produtos. Fonte não humana, categoria documentação.
Requisito 5. O sistema deve permitir que o administrador remova produtos que não são mais comercializados.
Fonte 1. Entrevista com o administrador. Fonte humana, nível operacional, classe de usuário administrador.
Fonte 2. Entrevista com o gerente responsável pelos produtos. Fonte humana, nível tático.
Requisito 6. O sistema deve impedir a remoção de um produto que esteja associado a pedidos já registrados, mantendo o histórico das vendas.
Fonte 1. Entrevista com o administrador. Fonte humana, nível operacional, classe de usuário administrador.
Fonte 2. Entrevista com o responsável financeiro/comercial. Fonte humana, nível tático.
Fonte 3. Documentação das regras de armazenamento e histórico de vendas. Fonte não humana, categoria documentação.
3. Processo: Controle de estoque
Requisito 7. O sistema deve permitir que o time de estoque registre a entrada de produtos, informando o produto e a quantidade recebida.
Fonte 1. Entrevista com o responsável pelo estoque. Fonte humana, nível operacional, classe de usuário estoque.
Fonte 2. Notas fiscais e documentos utilizados no recebimento de mercadorias. Fonte não humana, categoria documentação.
Requisito 8. O sistema deve dar baixa automaticamente na quantidade disponível de um produto após a confirmação de um pedido.
Fonte 1. Entrevista com o responsável pelo estoque. Fonte humana, nível operacional, classe de usuário estoque.
Fonte 2. Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.
Fonte 3. Sistema atual de controle de estoque, caso exista. Fonte não humana, categoria sistema legado.
Requisito 9. O sistema deve permitir que o time de estoque consulte a quantidade disponível de cada produto.
Fonte 1. Entrevista com o responsável pelo estoque. Fonte humana, nível operacional, classe de usuário estoque.
Fonte 2. Procedimento interno de controle de estoque. Fonte não humana, categoria documentação.
