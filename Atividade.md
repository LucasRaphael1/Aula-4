Atividade — Elicitação de Requisitos
Processo 1 — Registro de pedidos pelos vendedores
Requisito 1

Requisito: O sistema deve permitir que o vendedor registre um pedido informando os produtos, as respectivas quantidades e o cliente.

Fonte 1: Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.
Fonte 2: Procedimento atual de registro de pedidos. Fonte não humana, categoria documentação.

Requisito 2

Requisito: O sistema deve calcular automaticamente o valor total do pedido com base nos produtos e nas quantidades informadas.

Fonte 1: Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.
Fonte 2: Política comercial de preços da empresa. Fonte não humana, categoria documentação.

Requisito 3

Requisito: O sistema deve registrar a forma de pagamento escolhida pelo cliente no momento da venda.

Fonte 1: Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.
Fonte 2: Política comercial sobre as formas de pagamento aceitas. Fonte não humana, categoria documentação.

Processo 2 — Cadastro e remoção de produtos pelo administrador
Requisito 1

Requisito: O sistema deve permitir que o administrador cadastre um produto informando, no mínimo, nome, descrição, preço e código do produto.

Fonte 1: Entrevista com o administrador. Fonte humana, nível operacional, classe de usuário administrador.
Fonte 2: Padrão ou documentação utilizada atualmente para o cadastro de produtos. Fonte não humana, categoria documentação.

Requisito 2

Requisito: O sistema deve permitir que o administrador altere os dados de um produto já cadastrado.

Fonte 1: Entrevista com o administrador. Fonte humana, nível operacional, classe de usuário administrador.
Fonte 2: Procedimentos internos para manutenção do cadastro de produtos. Fonte não humana, categoria documentação.

Requisito 3

Requisito: O sistema deve permitir que o administrador remova um produto do catálogo, impedindo que ele seja utilizado em novos pedidos.

Fonte 1: Entrevista com o administrador. Fonte humana, nível operacional, classe de usuário administrador.
Fonte 2: Política interna para retirada de produtos do catálogo. Fonte não humana, categoria documentação.

Processo 3 — Controle de estoque
Requisito 1

Requisito: O sistema deve permitir que o funcionário do estoque registre a entrada de produtos e atualize automaticamente a quantidade disponível.

Fonte 1: Entrevista com o funcionário do estoque. Fonte humana, nível operacional, classe de usuário funcionário do estoque.
Fonte 2: Procedimento de recebimento e conferência de mercadorias. Fonte não humana, categoria documentação.

Requisito 2

Requisito: O sistema deve registrar a saída de produtos e reduzir automaticamente a quantidade disponível no estoque.

Fonte 1: Entrevista com o funcionário do estoque. Fonte humana, nível operacional, classe de usuário funcionário do estoque.
Fonte 2: Registros ou sistema atualmente utilizado para controle de estoque, caso exista. Fonte não humana, categoria sistema legado.

Requisito 3

Requisito: O sistema deve impedir o registro de uma saída quando a quantidade solicitada for maior que a quantidade disponível em estoque.

Fonte 1: Entrevista com o funcionário do estoque. Fonte humana, nível operacional, classe de usuário funcionário do estoque.
Fonte 2: Política interna de controle de estoque e disponibilidade de produtos. Fonte não humana, categoria documentação.
